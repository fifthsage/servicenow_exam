CIS-EM DRAFT GUIDE

Event Management 핵심 학습 지도 · 초안

외부 모니터링 이벤트를 수집·정규화하여 Alert로 만들고, 노이즈를 줄이며 서비스 영향과 대응으로 연결하는 흐름을 학습합니다.

INGESTION

이벤트 수집

  • Connector, MID Server, REST/SNMP 수집 경로
  • Event Field와 Source/Node/Resource
  • Event Rule과 Transform
  • 테스트 이벤트와 수집 상태 확인
ALERTS

Alert 처리

  • Event와 Alert의 차이
  • Message key와 중복 제거
  • Severity 변환과 상태 수명주기
  • CI Binding과 CMDB 품질
CORRELATION

상관분석과 영향도

  • Rule-based 및 자동 상관분석
  • Primary/Secondary Alert 관계
  • 서비스 맵 기반 영향도
  • 노이즈 감소와 Root Cause 후보
RESPONSE

대응과 운영

  • Alert Management Rule
  • Incident/Task 생성 조건
  • Remediation과 Flow 자동화
  • 대시보드, KPI, 튜닝과 보존 정책

핵심 구분

Event는 모니터링 도구가 보낸 원시 상태 변화이고, Alert는 Event Management가 운영 대응을 위해 정규화·추적하는 레코드입니다. CI Binding은 Alert를 CMDB CI에 연결하여 서비스 영향 분석의 기반을 만듭니다.

Alert 폭증 시 개별 Alert를 닫기 전에 message key, source/node/resource 값, 이벤트 규칙, 상관분석과 flapping 설정을 점검하세요.
