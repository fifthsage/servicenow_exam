CIS-DF 시험 전 최종 정리

기존 시험전 + 마지막 노트를 통합한 직전 점검본

1) 대시보드 3대장

Health Dashboard = 3C (Correctness, Compliance, Completeness)
Data Foundations Dashboard = Playbook, IRE 사용률, 개선 권고
CSDM Data Foundations Dashboard = CSDM 정렬 상태

Actionable, Playbook 키워드가 보이면 Data Foundations 가능성이 높습니다.

2) CSDM 도메인 핵심

도메인 핵심 키워드
Design Business Application, Information Object(PII/PCI)
Manage Technical Services Application Service, Technical Service, Infra CI
Sell / Consume Business Service, Service Offering, Consumer
Foundation Location, User, Group, Managed by group

3) 1초 컷 매칭

  • Attestation = 존재 여부 확인
  • Data Certification = 속성값 정확도 검증/수정
  • CMDB Data Manager = 정책 기반 정리/아카이브
  • Duplicate CI Remediator = 중복 CI 정리
  • CMDBTransformUtil = Import 시 IRE 경유
  • IRE 우선순위 = 숫자 작을수록 높음

4) 관계/라이프사이클/클래스 생성

  • Many-to-many: 로드밸런싱, 이중화 문맥에서 자주 출제
  • 신규 클래스는 Store 앱(Class Models) 확인 후 없을 때 확장
  • Legacy Status를 CSDM 표준 값으로 맞출 때 Lifecycle mapping 사용
  • Asset 클래스를 CI 확장 기준으로 고르는 선택지는 대개 오답입니다.

5) 시험 직전 체크리스트

  • 서비스 영향도: Business Service / Service Offering 문맥 확인
  • 데이터 품질: 3C, Health Inclusion Rules, Data Foundations Playbook 구분
  • 도구 위치: Workspace, Class Manager, Data Manager 역할 분리
  • 오답 패턴: Last Created, Asset 확장, 우선순위 숫자 해석 반대로 읽기
