CIS-SM DRAFT GUIDE

Service Mapping 핵심 학습 지도 · 초안

애플리케이션 서비스를 구성하는 CI와 관계를 발견하고, 정확한 서비스 맵을 운영하는 흐름을 중심으로 학습합니다.

FOUNDATIONS

서비스와 데이터 모델

  • Application Service, Entry Point, CI 관계
  • CSDM 및 CMDB 품질
  • 서비스 후보 선정과 범위 정의
  • 소유자·기술 담당자 협업
DISCOVERY

Top-down Mapping

  • MID Server와 Credential 준비
  • 진입점에서 연결을 따라가는 탐색
  • Pattern, Identification Section, Connection Section
  • 수동 연결과 Dynamic CI Group의 용도 구분
TRAFFIC

Traffic-based Discovery

  • 연결 데이터로 후보 관계 식별
  • Suggested Connection 검토
  • 정확성·노이즈·관찰 기간 관리
  • Tag 기반 서비스 정의와 적합한 사용 사례
OPERATIONS

운영과 문제 해결

  • Map 상태, 오류, 누락 CI 확인
  • Discovery log와 Pattern Debug
  • 중복 CI는 IRE와 식별 규칙부터 점검
  • 변경 후 재탐색과 맵 품질 검증

핵심 구분

Entry Point는 Top-down 탐색의 시작점이고, Pattern은 구성요소와 관계를 찾는 실행 로직입니다. Identification은 기존 CI를 고유하게 찾고, Connection은 다음 구성요소로 탐색을 이어갑니다.

맵 누락을 바로 수동 보완하기 전에 Credential, 방화벽, Pattern 단계, IRE 결과와 CMDB 관계를 차례로 확인하세요.
