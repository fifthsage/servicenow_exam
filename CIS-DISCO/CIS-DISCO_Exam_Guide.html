홈CIS-DISCO 홈

시험 명칭 확인 · 초안

ServiceNow University의 현재 Blueprint 제목은 Certified Implementation Specialist - Discovery (CIS-DISCO) Mainline Exam Blueprint입니다. `CIS-DF`는 Data Foundations이고 Discovery 시험의 약칭이 아니므로 구분해야 합니다.

공식 확인 경로

  • CIS-DISCO Mainline Exam Blueprint (KB0011545)
  • Discovery Product Documentation
  • ServiceNow University의 Discovery 과정 및 실습
  • 공식 연습시험이 제공되는 경우 ServiceNow가 안내하는 MeasureUp 경로

문제 출처 정책

ServiceNow는 공식 교육 자료와 Product Documentation을 시험의 기준으로 안내합니다. 인터넷의 “actual dump”는 최신성, 정답 정확성, 시험 보안 및 저작권을 보장할 수 없습니다. 이 허브는 공개된 공식 샘플 4문항과 공식 범위에 맞춰 새로 작성한 연습문항을 사용합니다.

현재 초안의 한계

  • 공개 레거시 Specification은 약 45문항과 4개 영역을 명시하지만, 현재 시험 수·시간·가중치는 최신 Blueprint에서 다시 확인해야 합니다.
  • 실전 모드는 일반적인 CIS 대비값인 60문항/90분으로 설정했으며, 문제 풀이 시 현재 풀 크기만큼 자동 제한됩니다.
  • 릴리스별 Pattern, Cloud Discovery, Agent Client Collector, IRE 변경 사항은 최신 문서로 보강해야 합니다.
